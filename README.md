# nZO Innovations - Corporate Website

Premium corporate website for **nZO Innovations (Pvt) Ltd** - Technology Consulting & Solution Advisory.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3020](http://localhost:3020)

## Logo assets

| File | Usage |
|------|--------|
| `public/nzo-icon.png` | Header, footer, favicon (36×36 px) |
| `public/nzo-logo-full.png` | Social sharing / Open Graph |
| `src/app/icon.png` | Browser tab favicon |
| `src/app/apple-icon.png` | Apple touch icon |

Logo mark dimensions: **36×36 px**, border radius **8 px**, retina **72×72 px**.

## Configuration

Update company details in `src/lib/constants.ts`.
